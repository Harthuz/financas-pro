🚨 REGRA #1 (OBRIGATÓRIA): Backup em CSV Antes de Qualquer Lote de Modificação

SEMPRE faça backup antes de qualquer lote de modificação (criação, edição ou exclusão de gastos, categorias ou contas). O backup deve ser salvo em formato CSV na pasta Downloads (~/Downloads) do próprio dispositivo que estiver fazendo a modificação via MCP ou API.

  • Via MCP: Execute obrigatoriamente a ferramenta fazer_backup_csv() antes de chamar adicionar_gasto, atualizar_gasto, excluir_gasto, adicionar_categoria ou adicionar_conta.
  • Via Terminal (Linux / macOS no dispositivo cliente): 
    curl -fSL "http://192.168.15.15:8000/api/exportar" -o "$HOME/Downloads/gastos_backup_$(date +%Y%m%d_%H%M%S).csv"
  • Via PowerShell (Windows no dispositivo cliente): 
    Invoke-WebRequest -Uri "http://192.168.15.15:8000/api/exportar" -OutFile "$HOME\Downloads\gastos_backup_$(Get-Date -Format 'yyyyMMdd_HHmmss').csv"

📌 Regras de Negócio para Lançamento de Finanças

  1. Backup Primeiro: Garanta que o CSV de backup foi salvo em ~/Downloads no dispositivo que fará a alteração antes de iniciar o lote.
  2. Verifique primeiro: Sempre consulte as categorias e contas existentes (via obter_metadados no MCP ou GET /api/metadados na API) antes de realizar inserções.
  3. Reutilize padrões: Utilize o padrão exato de nomenclatura das categorias (tipo) e métodos de pagamento (conta) já cadastrados.
  4. NUNCA crie sem permissão: Se o gasto não se encaixar em nenhuma categoria ou conta existente, pause e pergunte expressamente ao usuário se ele deseja criar a categoria/conta nova ou usar uma já existente.
  5. Formato dos Campos:
    • nome: Texto descritivo (se terminar em 1/N ou (1/N), ex: Compra - 1/6, o backend criará automaticamente as parcelas seguintes nos próximos meses).
    • valor: Número decimal em R$ (ex: 34.15).
    • tipo: Nome exato da Categoria.
    • conta: Nome exato da Conta / Método de Pagamento.
    • data: Data no formato YYYY-MM-DD.

🔌 Como Conectar Outro PC da Rede via MCP

Qualquer computador na rede pode usar o servidor MCP apontando para a API central (http://192.168.15.15:8000). Assim, quando a ferramenta fazer_backup_csv() for chamada, o backup CSV será salvo diretamente na pasta ~/Downloads do computador que estiver executando o MCP.

# 1. Baixe o script MCP atualizado
curl -fSL http://192.168.15.15:8084/mcp_server.py -o ~/mcp_server.py

# 2. Instale as bibliotecas necessárias
pip install mcp requests

Adicione no arquivo mcp_config.json do agente no outro PC:

{
  "mcpServers": {
    "financas": {
      "command": "python3",
      "args": ["/caminho/para/mcp_server.py"],
      "env": {
        "FINANCAS_API_URL": "http://192.168.15.15:8000"
      }
    }
  }
}

🛠️ Ferramentas MCP & Endpoints da API

Ferramenta MCP Endpoint REST Equivalente Descrição
fazer_backup_csv(nome_arquivo?) GET /api/exportar Obrigatório antes de modificações. Salva CSV em ~/Downloads.
obter_metadados() GET /api/metadados Lista nomes de todas as categorias (tipos) e contas.
listar_gastos() GET /api/gastos Lista todos os gastos cadastrados.
adicionar_gasto(...) POST /api/gastos Cria novo gasto (nome, valor, tipo, conta, data).
atualizar_gasto(gasto_id, ...) PATCH /api/gastos/:id Atualiza campos de um gasto existente.
excluir_gasto(gasto_id) DELETE /api/gastos/:id Remove um gasto pelo ID.
listar_categorias() GET /api/categorias Lista categorias com contagem de gastos vinculados.
adicionar_categoria(nome, cor?) POST /api/categorias Cria nova categoria (apenas com permissão do usuário).
listar_contas() GET /api/contas Lista contas/métodos de pagamento com contagem de gastos.
adicionar_conta(nome, tipo_conta?, cor?) POST /api/contas Cria nova conta (apenas com permissão do usuário).
