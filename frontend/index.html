Servidor MCP & API HTTP de Controle de Finanças (Porta 8080)

Este servidor na porta 8080 (http://192.168.15.15:8080) expõe diretamente o MCP de Finanças, a Zona de Stage de Extratos (/stage) e a API REST completa para leitura (GET em tudo) e lançamento de novas compras (POST).

0. Zona de Stage / Transição de Extratos Bancários (Playground MCP — /stage)

Quando o agente comparar os extratos bancários com as baixas já registradas (GET /api/gastos), envie as compras novas ainda não baixadas (mesmo com colunas incompletas que o usuário precisará preencher) para o Stage:

  • Interface Web do Stage (Planilha de Revisão e Baixa em 1 Clique): http://192.168.15.15:8080/stage
  • Listar Itens no Stage: GET http://192.168.15.15:8080/api/stage (ou MCP listar_stage)
  • Enviar 1 ou Lote de Itens do Extrato para o Stage: POST http://192.168.15.15:8080/api/stage (ou MCP adicionar_stage) 
    {
  "limpar_anterior": false,
  "itens": [
    {
      "data": "2026-11-02",
      "nome": "",
      "valor": 89.90,
      "tipo": "",
      "conta": "Crédito Nubank",
      "descricao": "",
      "localizacao": "",
      "texto_extrato": "02/11 PAG*MERCADOLIVRE R$ 89,90",
      "observacao_agente": "Não consegui inferir o item comprado nem a categoria"
    }
  ]
}
  • Dar Baixa Definitiva nos Itens Prontos do Stage: POST http://192.168.15.15:8080/api/stage/commit (ou clicar no botão Dar Baixa em /stage)

1. Como dar GET em tudo na porta 8080

  • GET Tudo Consolidado (Metadados + Categorias + Contas + Todos os Gastos): GET http://192.168.15.15:8080/api/tudo
  • GET Todos os Gastos: GET http://192.168.15.15:8080/api/gastos (filtro opcional: ?search=termo)
  • GET Metadados (Categorias, Contas, Locais e Orçamentos): GET http://192.168.15.15:8080/api/metadados
  • GET Categorias: GET http://192.168.15.15:8080/api/categorias
  • GET Contas / Métodos de Pagamento: GET http://192.168.15.15:8080/api/contas
  • GET Backup CSV Completo (Obrigatório antes de modificações): GET http://192.168.15.15:8080/api/exportar
  • GET Manifesto MCP e Ferramentas: GET http://192.168.15.15:8080/mcp
  • GET Diretrizes Completas (Markdown): GET http://192.168.15.15:8080/DIRETRIZES.md

2. Regras Obrigatórias Antes de Dar Entrada em Novas Compras

  1. Backup CSV Primeiro: Antes de adicionar, editar ou excluir qualquer gasto, baixe o backup CSV em GET http://192.168.15.15:8080/api/exportar (ou execute a ferramenta MCP fazer_backup_csv) salvando em ~/Downloads/gastos_backup_YYYYMMDD_HHMMSS.csv.
  2. Verifique Categorias e Contas Existentes: Consulte GET http://192.168.15.15:8080/api/metadados (ou GET http://192.168.15.15:8080/api/tudo) e reutilize exatamente os nomes de tipo (categoria) e conta (método de pagamento) existentes. Nunca crie categoria ou conta nova sem perguntar ao usuário.

3. Como dar Entrada de Novas Compras (POST na porta 8080)

Opção A — Via REST API na porta 8080: POST http://192.168.15.15:8080/api/gastos (ou POST http://192.168.15.15:8080/mcp/tools/adicionar_gasto)

{
  "nome": "Nome da Compra (se terminar com 1/N, ex: 'Tênis - 1/6', gera as N parcelas automaticamente)",
  "valor": 45.90,
  "tipo": "Alimentação",
  "conta": "Crédito Nubank",
  "data": "2026-11-02",
  "descricao": "Descrição opcional da compra",
  "localizacao": "Estabelecimento ou endereço opcional"
}

Opção B — Via Protocolo MCP (JSON-RPC 2.0 Streamable-HTTP na porta 8080): POST http://192.168.15.15:8080/mcp

{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "adicionar_gasto",
    "arguments": {
      "nome": "Almoço",
      "valor": 45.90,
      "tipo": "Alimentação",
      "conta": "Crédito Nubank",
      "data": "2026-11-02",
      "descricao": "Restaurante",
      "localizacao": "Centro"
    }
  }
}

4. Outras Operações e Ferramentas MCP na Porta 8080

  • Atualizar Gasto: PATCH http://192.168.15.15:8080/api/gastos/:id ou POST http://192.168.15.15:8080/mcp/tools/atualizar_gasto
  • Excluir Gasto: DELETE http://192.168.15.15:8080/api/gastos/:id ou POST http://192.168.15.15:8080/mcp/tools/excluir_gasto
  • Conectar Cliente MCP via Rede (HTTP / SSE): URL Streamable-HTTP: http://192.168.15.15:8080/mcp | URL SSE: http://192.168.15.15:8080/sse
  • Baixar Script MCP Python (stdio): GET http://192.168.15.15:8080/mcp_server.py
